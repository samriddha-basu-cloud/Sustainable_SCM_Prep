## About the numericals ⭐⭐⭐
Every numerical that appears in the slides is reproduced as the **exact problem from the zip**: the Lecture 6 weighted-score model and VoltTech scorecard, TOPSIS and the risk matrix; the carbon deck's ICEV + EV plant (Scopes 1, 2, 3); the Lecture 8 network A/B/C and the 10,000-returns allocation; the Lecture 10 FMCG distribution network; the Lecture 3 dashboard; and the Lecture 9 TAS / Navya exercise. Each comes with a full worked answer. The slides give the questions but rarely the answers. Where a slide's own arithmetic is inconsistent (the VoltTech band, the TOPSIS ranks, the carbon-credit ranges), the page says so and shows the correct working. Each page then adds **practice problems** (📗) in the same style, with answers hidden under Self-test. Where a question cannot be solved without an assumption, the assumption is written in **bold** before the working. Do the same in the exam: **state the assumption, show the formula, show the substitution, box the answer, interpret it in one line, and recommend.**

## Exam-day answer tips ⭐⭐
- **Supplier scoring (CO2)**: table of score × weight → total → rank → *sensitivity* (does a weight change flip the winner?) → knock-out criteria (human rights, safety) → recommendation with a development plan for the runner-up.
- **Carbon (CO3)**: classify each source by scope **first**, then activity × factor (show units, convert kg → t), then a summary table with shares, intensity per unit, and the top lever (usually Scope 3 purchased goods or use phase).
- **Network (CO4)**: write the objective Z = C + λE + μW, compute cost *and* CO₂ for each option, find the switching λ or the minimum-cost number of DCs, then check service (OTIF) and resilience.
- **Performance (CO5)**: formula → value → compare with target → leading or lagging → owner → corrective action. Finish with the five tests (material, balanced, actionable, comparable, credible).
- **3-markers (CO1, CO6)**: definition + three points + one Indian example.
- Draw: the closed-loop network (nine nodes), the R-ladder, the net-zero hierarchy, the Scope 1-2-3 boundary diagram, the technology decision matrix, the SSCM performance loop.
